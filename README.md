# 造園施工管理 第一次検定 学習アプリ

一級・二級造園施工管理技術検定の **第一次検定**（合格で「技士補」。第二次検定合格で「施工管理技士」）に向けた、個人用・日本語・スマホ優先の学習Webアプリです。
バックエンド・ログイン・外部AI APIは不要。学習記録はブラウザのIndexedDBに保存されます。

## 起動

```bash
npm install
npm run dev        # 開発サーバー (http://localhost:5173、使用中なら次のポート)
npm run build      # 型チェック + 本番ビルド (dist/)
npm run preview    # ビルド結果の確認
npm test           # 単体テスト
npm run typecheck  # 型チェックのみ
```

スマホで使うときは `npm run dev` / `npm run preview` の Network URL（同じWi‑Fi内）を開くか、`dist/` を任意の静的ホスティングに置いてください。
学習記録は端末・ブラウザごとに別です。端末を変えるときは「記録」タブでエクスポート／復元してください。

## 機能

- **ホーム**: 今日の10分学習、今日の復習件数、学習日数・解答数・分野別正答率、続きから再開、二級／一級の目標日（未設定が初期値）
- **学ぶ**: 8分野×1本のレッスン（目的→用語（読み付き）→具体例→間違えやすい点→ゴロ付き暗記ポイント）と暗記カード
- **問題**: 一問一答（単一／複数選択）。級・分野・未回答・苦手・思い込みミス・ブックマークで絞り込み。理解度チェック（10/20問、時間制限は任意）
- **復習**: 翌日→3日→7日→14日→30日。誤答は当日中に再出題。「自信あり」での誤答は「思い込みミス」として最優先
- **記録**: 成績、ブックマーク、誤り報告、学習記録のエクスポート／復元、問題・レッスンのJSON追加（検証＋プレビュー付き）、削除（確認付き）

### 公式過去問の答え合わせ（問題タブ）
公式PDFの転載条件が確認できないため、問題文は収録していません。公式PDFを開いて解き、選んだ番号をアプリに入力すると、公式の正答番号（正答肢PDFを転記）で採点し、分野別集計・復習（見直し）に反映します。
収録：令和8年度 一級 第一次(問題A 36問/B 29問)、令和8年度 二級 第一次(前期)40問、令和7年度 二級 第一次40問。データは `src/data/official.ts`。
公式サイト(jctc.jp)に第一次検定として掲載があるのは令和7・8年度のみで、過去10年分は入手できませんでした。合格基準点は公式資料で確認できていないため合否判定は表示しません。

### 暗記重視の仕様
- 解答は「自信あり／迷った／分からない」で提出。誤答すると**正解を選び直すまで次へ進めない**
- 解答後に「覚え方（ゴロ）」を大きく表示（アプリ独自の記憶補助で、公式の解説ではありません）
- 自信あり正解が3回連続で「定着」。迷った正解は間隔を進めず翌日に再出題

## 構成

`src/data/` レッスン・問題・出典 / `src/lib/` 採点・復習間隔・出題選択・検証・IndexedDB / `src/screens/` 各タブ / `src/Runner.tsx` 解答画面。
問題を追加するJSONの形式は `docs/sample-import.json`（アプリ内からもダウンロード可）を参照。
正式な模擬試験の条件は `src/lib/exams.ts` に確認済みの数値のみ追加します（現在は空）。
